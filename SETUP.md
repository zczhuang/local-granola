# Oatmeal: Mac setup

Oatmeal is a local-only fork of [fastrepl/anarlog](https://github.com/fastrepl/anarlog) (MIT, see `LICENSE`), adapted to run fully on an Apple Silicon Mac. Meeting audio, transcripts, and notes stay on your Mac, and summaries are generated by a local [Ollama](https://ollama.com) model.

## What Oatmeal adds on top of Anarlog

1. **Local lockdown (`LOCAL_ONLY`).** Built with Rust `ANARLOG_LOCAL_ONLY` and TypeScript `VITE_LOCAL_ONLY` enabled by default.
   - Off and locked: telemetry, crash reports, cloud sync, the auto-updater, hosted LLM and STT providers, sign-in, and the cloud API.
   - Web requests are restricted to localhost (plus direct Google Calendar OAuth/API calls if you choose to connect Google Calendar).
   - Audio is deleted after transcription by default; you can keep recordings for N days in **Settings → Audio**.
2. **On-device transcription.** Live transcription uses **Parakeet v3 Live** on the Neural Engine (or **Apple Speech**). After ~30 seconds of speech, a language check decides whether the meeting is Mandarin or mixed; if so, a **Whisper large-v3-turbo** pass can rerun the full meeting afterward.
3. **Granola-style meeting detection & auto-summary.** Dedicated meeting apps (Zoom, Microsoft Teams, Webex, Slack) trigger a `Meeting detected` / `Take notes` notification within 3 seconds, auto-stop capture ~5 seconds after the call ends, and automatically switch the session into **Summary** mode.
4. **Direct local Google Calendar & Apple Calendar.** Connect Google Calendar directly from your Mac using your own Google Cloud Desktop OAuth 2.0 client (PKCE + loopback) with zero cloud relay, or sync native Apple Calendar. Scheduled meeting auto-start and auto-join work locally.
5. **Speakers.** Separates microphone and system audio channels, reads Zoom and Teams speaking cues from macOS Accessibility, and combines them with voiceprints and calendar attendees.
6. **Enhanced notes.** Your typed lines stay verbatim as the backbone.
   - AI bullets appear underneath your lines with clickable timestamped citations back to the transcript.
   - Summaries automatically match the spoken language of the transcript and chunk long multi-hour meetings across overlapping windows.
   - Re-enhancing preserves your edits and respects deletions; **Regenerate** refreshes AI bullets while keeping your typed notes.
   - Recommended Ollama models: `gemma4:26b-mlx` (best quality, ~18–20 GB GPU RAM) or `gemma4:12b-mlx` (~8–10 GB GPU RAM, great if sharing Ollama with another local app on 32 GB Macs).
7. **MCP for Claude Code, Codex, and Antigravity.** `oatmeal-mcp` (`anarlog-cli`) is a read-only stdio MCP server over your local SQLite database. See [docs-local/MCP.md](docs-local/MCP.md).

## 0. Prerequisites

- **macOS on Apple Silicon** (32 GB+ RAM recommended for `gemma4:26b-mlx`; 16–24 GB works well with `gemma4:12b-mlx`).
- **Xcode** (full app) with its Metal Toolchain:
  ```sh
  DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer xcodebuild -downloadComponent MetalToolchain
  ```
- **Node.js 22+**, **pnpm 11.1.1**, **Rust 1.94.0** (`rustup` reads `rust-toolchain.toml`), and `brew install process-compose`.
- **Ollama for macOS**, running (`ollama serve` or the menu bar app).
- **Avoid spaces in `CARGO_TARGET_DIR`:** some native C dependencies (such as `mp3lame-sys`) fail if the build target path contains spaces. Always export a path without spaces:

  ```sh
  export CARGO_TARGET_DIR="$HOME/.cargo-target/oatmeal"
  ```

## 1. Clone and install

```sh
git clone https://github.com/zczhuang/oatmeal.git
cd oatmeal
pnpm install
```

## 2. Pull local models

```sh
ollama pull gemma4:26b-mlx   # ~17 GB; highest quality meeting notes
# or:
ollama pull gemma4:12b-mlx   # ~7.7 GB; lighter footprint on 16–32 GB Macs
```

Parakeet v3 Live and Whisper large-v3-turbo download directly inside Oatmeal under **Settings → Transcription**.

## 3. Run or build `Oatmeal.app`

### Development mode

```sh
export CARGO_TARGET_DIR="$HOME/.cargo-target/oatmeal"
pnpm dev:desktop
```

### Release macOS app bundle

```sh
export CARGO_TARGET_DIR="$HOME/.cargo-target/oatmeal"
export SDKROOT="$(xcrun --sdk macosx --show-sdk-path)"
pnpm -F @anlg/desktop tauri build --bundles app --config src-tauri/tauri.conf.stable.json
```

Tip: Sign `/Applications/Oatmeal.app` with your own Apple Development certificate (`codesign --force --sign "<CERT>" --entitlements apps/desktop/src-tauri/Entitlements.plist ...`) so macOS Microphone, System Audio, Calendar, and Accessibility permissions persist across rebuilds.

## 4. First-run setup in Oatmeal

1. Grant **Microphone**, **Screen & System Audio Recording**, and **Accessibility** (Accessibility enables live Zoom/Teams speaker cues).
2. **Settings → Transcription:** Download **Parakeet v3** (and optionally **Whisper large-v3-turbo**) and select **Parakeet v3 Live** as the live model.
3. **Settings → Intelligence:** Choose **Ollama** and select `gemma4:26b-mlx` (or `gemma4:12b-mlx`).
4. **Calendar (optional):** Enable **Apple Calendar**, or connect **Google Calendar** by pasting your Google Cloud Desktop OAuth client JSON (`client_secret_*.json` with Google Calendar API enabled). Credentials are stored locally at `~/Library/Application Support/com.hyprnote.stable/google-calendar-oauth.json` with `0600` permissions.

## 5. Connect Claude Code, Codex, and Antigravity (MCP)

Full instructions are in [docs-local/MCP.md](docs-local/MCP.md). Quick install:

```sh
export CARGO_TARGET_DIR="$HOME/.cargo-target/oatmeal"
cargo build --release -p anarlog-cli
mkdir -p ~/.local/bin
rm -f ~/.local/bin/oatmeal-mcp
cp "$CARGO_TARGET_DIR/release/anarlog" ~/.local/bin/oatmeal-mcp
codesign --force --sign - ~/.local/bin/oatmeal-mcp

# Claude Code
claude mcp add --scope user oatmeal -- ~/.local/bin/oatmeal-mcp \
  --db-path "$HOME/Library/Application Support/anarlog/app.db" mcp
```

## 6. What can still reach the network

- Model downloads you explicitly start: `models.anarlog.so` (Parakeet, Whisper) and Hugging Face.
- Direct Google Calendar OAuth (`accounts.google.com`, `oauth2.googleapis.com`, `www.googleapis.com`), **only** if you connect Google Calendar.
- Ollama itself, only if you point it at a remote model (Oatmeal refuses non-loopback Ollama URLs).

Everything else (analytics, telemetry, crash reporting, cloud sync, hosted AI, auto-updater) is disabled at build time.
