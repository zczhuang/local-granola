## Default Permission

Default permissions for the plugin

#### This default permission set includes the following:

- `allow-export`
- `allow-get-google-drive-sync-status`
- `allow-save-google-drive-credentials`
- `allow-connect-google-drive`
- `allow-disconnect-google-drive`
- `allow-update-google-drive-sync-config`
- `allow-sync-notes-to-google-drive`
- `allow-get-zoom-sync-status`
- `allow-save-zoom-credentials`
- `allow-connect-zoom`
- `allow-disconnect-zoom`
- `allow-update-zoom-sync-config`
- `allow-sync-zoom-meetings`
